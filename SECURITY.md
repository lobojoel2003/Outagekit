# Security policy

Outagekit stores everything on the user's own device and sends nothing over
the network. Even so, a bug that gives a wrong runtime could put someone at
risk, so we treat **calculation errors as safety issues**.

## Reporting

- **Wrong runtime or plan advice:** open an issue with the setup that produced
  it (or a backup file with personal details removed). These are fixed first.
- **Security vulnerabilities:** please use GitHub's
  [private vulnerability reporting](https://github.com/lobojoel2003/Outagekit/security/advisories/new)
  rather than a public issue.

We aim to reply within a week. Fixes ship as a patch release.

## Supported versions

Only the latest release receives fixes.
